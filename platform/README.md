# platform: публічний API

Сервіс на FastAPI. Віддає розклади й статистику, згодом додасть API-ключі, акаунти та
сповіщення. Mongo, яку наповнює `parser/`, він тільки читає. Telegram-сесії тут немає:
вона живе лише в контейнері парсера (ADR-0002).

Стан: ще не почато.

## Контракт

- `/v1/...`: новий версіонований API, OpenAPI-специфікацію генерує FastAPI.
- `/api/...`: перехідний шар у тому ж форматі, що й у TS-бекенді, щоб наявні фронти
  не зламались під час переходу. Зникне, коли клієнти перейдуть на `/v1`.

## Стек

Python 3.12, uv, FastAPI, pydantic v2, pymongo (`AsyncMongoClient`).
Перевірки: ruff, mypy --strict, pytest, testcontainers.

## Правила

- Як і в парсері, домен не залежить від FastAPI і Mongo, адаптери лежать окремо.
- Помилки віддаються у форматі RFC 9457 Problem Details.
- Формули статистики описані в `docs/stats-api.md` і перевіряються на еталонних наборах.
