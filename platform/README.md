# platform — публічний API (етап 2)

FastAPI-сервіс: віддає розклади й статистику, згодом — API-ключі, акаунти, сповіщення.
**Лише читає** Mongo, яку наповнює `parser/`. Telegram-сесії тут нема і не буде —
вона живе тільки в контейнері парсера (ADR-0002).

Статус: не почато. План — `plan-stage-2` у пам'яті проєкта.

## Контракт
- `/v1/...` — новий версіонований API для екосистеми; OpenAPI генерує FastAPI.
- `/api/...` — **перехідний** шар тієї ж форми, що в TS-бекенді, щоб React-фронт і фронт
  іншого студента не зламались при перемиканні. Прибирається, коли клієнти перейдуть на `/v1`.

## Стек
Python 3.12 · uv · FastAPI · pydantic v2 · pymongo (`AsyncMongoClient`; Motor депрекейтнутий)
ruff · mypy --strict · pytest + testcontainers

## Правила
- Hexagonal-lite, як у парсері: домен без FastAPI і Mongo, адаптери окремо.
- Помилки — RFC 9457 Problem Details.
- Формули stats — специфікація в `docs/stats-api.md`; перевіряються еталонними наборами.
