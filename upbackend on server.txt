Розгортання на Armbian сервері (Docker)

═══════════════════════════════════════════════
0. Підключення до сервера
═══════════════════════════════════════════════

ssh user@IP_ВАШОГО_СЕРВЕРА

═══════════════════════════════════════════════
1. Перевірка архітектури
═══════════════════════════════════════════════

uname -m
# aarch64 = 64-bit ✓ (Docker + MongoDB повністю підтримуються)
# armv7l  = 32-bit → MongoDB не підтримується, використайте MongoDB Atlas

═══════════════════════════════════════════════
2. Оновлення системи
═══════════════════════════════════════════════

sudo apt update && sudo apt upgrade -y

═══════════════════════════════════════════════
3. Встановлення Docker
═══════════════════════════════════════════════

curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# ВАЖЛИВО: перелогіньтесь щоб група застосувалась
exit
# підключіться знову: ssh user@IP_ВАШОГО_СЕРВЕРА

# Перевірка
docker --version
docker compose version

═══════════════════════════════════════════════
4. Встановлення Git і клонування репозиторію
═══════════════════════════════════════════════

sudo apt install -y git

git clone https://github.com/NeToR-YT/API-queues-of-lights-off-in-areas.git
cd API-queues-of-lights-off-in-areas

═══════════════════════════════════════════════
5. Конфігурація
═══════════════════════════════════════════════

nano backend-js/config.json

Вставте і заповніть:

{
  "api_id": ВАШ_API_ID,
  "api_hash": "ВАШ_API_HASH",
  "session_string": "",
  "channels": [
    { "id": 1, "name": "Черкаси",    "username": "pat_cherkasyoblenergo" },
    { "id": 2, "name": "Запоріжжя", "username": "Zaporizhzhyaoblenergo_news" },
    { "id": 3, "name": "Миколаїв",  "username": "mk_energy_ua" },
    { "id": 4, "name": "Харків",    "username": "kharkivenergy" }
  ],
  "batch_parser": {
    "batch_size": 2,
    "batch_delay": 5,
    "limit_messages": 200
  },
  "timezone_offset": 3,
  "update_interval_minutes": 15,
  "cors_origins": ["http://localhost:3000", "http://localhost:5173"],
  "mongodb_uri": "mongodb://mongo:27017",
  "mongodb_db": "queues"
}

Зберегти: Ctrl+O → Enter → Ctrl+X

ВАЖЛИВО: mongodb_uri має бути "mongodb://mongo:27017" (не 127.0.0.1)
         "mongo" — це назва сервісу в docker-compose

═══════════════════════════════════════════════
6. Збірка Docker образу
═══════════════════════════════════════════════

docker compose build backend

═══════════════════════════════════════════════
7. Перший запуск — авторизація Telegram
═══════════════════════════════════════════════

Запустіть MongoDB і бекенд інтерактивно:

docker compose up -d mongo
docker compose run --rm -it backend node dist/app.js

У терміналі з'явиться:

  Phone number: +380XXXXXXXXX
  Code: 12345
  Password (if enabled): ****

Після "API listening on port 5000" — сесія збережена.
Зупиніть: Ctrl+C

Перевірте що session_string з'явився в config.json:

cat backend-js/config.json | grep session_string

═══════════════════════════════════════════════
8. Запуск у фоні
═══════════════════════════════════════════════

docker compose up -d backend mongo

Перевірка:

docker compose ps
docker compose logs -f backend

Перевірка API:

curl http://localhost:5000/api/status
curl http://localhost:5000/api/cities

═══════════════════════════════════════════════
9. Автозапуск після перезавантаження сервера
═══════════════════════════════════════════════

sudo nano /etc/systemd/system/gpv-api.service

Вставте:

[Unit]
Description=GPV API (Docker Compose)
After=docker.service
Requires=docker.service

[Service]
Type=simple
User=YOUR_USER
WorkingDirectory=/home/YOUR_USER/API-queues-of-lights-off-in-areas
ExecStart=docker compose up backend mongo
ExecStop=docker compose stop backend mongo
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target

Замініть YOUR_USER на вашого користувача (whoami)

sudo systemctl daemon-reload
sudo systemctl enable gpv-api
sudo systemctl start gpv-api

═══════════════════════════════════════════════
Корисні команди
═══════════════════════════════════════════════

# Логи в реальному часі
docker compose logs -f backend

# Перезапустити бекенд
docker compose restart backend

# Зупинити все
docker compose stop

# Оновити код з GitHub і перебілдити
git pull
docker compose build backend
docker compose up -d backend

# Ручний запуск парсера
docker compose exec backend node dist/app.js

# Зайти в контейнер
docker compose exec backend sh
