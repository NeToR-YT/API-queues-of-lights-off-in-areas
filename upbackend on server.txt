Розгортання на Armbian сервері
0. Підключення до сервера

ssh user@IP_ВАШОГО_СЕРВЕРА
1. Оновлення системи

sudo apt update && sudo apt upgrade -y
2. Встановлення Node.js 18+

curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
node --version  # має показати v18.x.x
3. Встановлення MongoDB
Важливо: Armbian 64-bit (aarch64) підтримується офіційно. Якщо у вас 32-bit — перейдіть до альтернативи нижче.

Перевірте архітектуру:


uname -m
# aarch64 = 64-bit ✓
# armv7l  = 32-bit → читайте нижче
64-bit (aarch64):


curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor

echo "deb [ arch=arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list

sudo apt update && sudo apt install -y mongodb-org

sudo systemctl enable mongod
sudo systemctl start mongod
32-bit (armv7l) — альтернатива:


# Старий MongoDB з репозиторію Debian (може бути версія 3.x)
sudo apt install -y mongodb
sudo systemctl enable mongodb
sudo systemctl start mongodb
Або використайте MongoDB Atlas (хмарна безкоштовна версія) і просто вкажіть URI в config.json.

Перевірка:


mongosh --eval "db.runCommand({ connectionStatus: 1 })"
# або для старого mongo: mongo --eval "db.runCommand({ connectionStatus: 1 })"
4. Встановлення Git і клонування репозиторію

sudo apt install -y git

git clone https://github.com/NeToR-YT/API-queues-of-lights-off-in-areas.git
cd API-queues-of-lights-off-in-areas/backend-js
5. Встановлення залежностей

npm install
6. Конфігурація

nano config.json
Заповніть файл:


{
  "api_id": "ваш_api_id",
  "api_hash": "ваш_api_hash",
  "session_string": "",
  "channels": [
    { "id": 1, "name": "Черкаси",    "username": "pat_cherkasyoblenergo" },
    { "id": 2, "name": "Запоріжжя", "username": "Zaporizhzhyaoblenergo_news" },
    { "id": 3, "name": "Миколаїв",  "username": "mk_energy_ua" },
    { "id": 4, "name": "Харків",    "username": "kharkivenergy" }
  ],
  "batch_parser": {
    "batch_size": 2,
    "batch_delay": 5,
    "limit_messages": 50
  },
  "timezone_offset": 2,
  "mongodb_uri": "mongodb://127.0.0.1:27017",
  "mongodb_db": "queues"
}
Зберегти: Ctrl+O → Enter → Ctrl+X

7. Перший запуск (авторизація Telegram)
Перший раз треба запустити інтерактивно щоб ввести код:


node src/app.js
У терміналі з'явиться:


Phone number: +380XXXXXXXXX
Code: 12345
Після успішного входу session_string автоматично збережеться в config.json. Зупиніть процес Ctrl+C.

8. Налаштування автозапуску через systemd

sudo nano /etc/systemd/system/gpv-api.service

[Unit]
Description=GPV API
After=network.target mongod.service
Wants=mongod.service

[Service]
Type=simple
User=YOUR_USER
WorkingDirectory=/home/YOUR_USER/API-queues-of-lights-off-in-areas/backend-js
ExecStart=/usr/bin/node src/app.js
Restart=on-failure
RestartSec=10
Environment=PORT=5000

[Install]
WantedBy=multi-user.target
Замініть YOUR_USER на вашого користувача (перевірити: whoami)


sudo systemctl daemon-reload
sudo systemctl enable gpv-api
sudo systemctl start gpv-api
Перевірка:


sudo systemctl status gpv-api
# або переглянути логи:
sudo journalctl -u gpv-api -f
9. Перевірка роботи API

curl http://localhost:5000/api/status
curl http://localhost:5000/api/cities
Корисні команди після деплою

# Перезапустити після змін у коді
sudo systemctl restart gpv-api

# Переглянути логи в реальному часі
sudo journalctl -u gpv-api -f

# Оновити код з GitHub
cd ~/API-queues-of-lights-off-in-areas
git pull
cd backend-js && npm install
sudo systemctl restart gpv-api

# Ручний запуск парсера
cd ~/API-queues-of-lights-off-in-areas/backend-js
node src/fetcher.js
